# DocxCraft для Codex на Windows

В PowerShell из корня репозитория соберите локальный пакет. Укажите папку, где
лежат документы. Плагин читает и сохраняет файлы в пределах этой папки.

```powershell
& ./scripts/package-codex-plugin.ps1 -DocumentRoot 'C:\Documents\Contracts'
codex plugin marketplace add ./dist/codex-docxcraft
```

В каталоге плагинов Codex выберите **DocxCraft Local** и установите **DocxCraft**.
Если источник ещё не появился, перезапустите приложение. Проверьте установку
в новом чате Codex, чтобы он загрузил инструменты плагина.

Укажите путь к локальному файлу и вызовите навык `$docx-review`. Примеры запросов:

- «Проверь раздел об оплате и предложи формулировки для неясных условий».
- «В пункте 4.2 замени 30 дней на 15 дней. В таблице цен замени 100 000 руб. на
  120 000 руб. Верни копию с исправлениями».

Правки текста в абзацах и ячейках записываются как исправления Word.
Гиперссылки, поля, управляющие элементы и прежние правки можно оставить рядом
с изменяемым фрагментом. По умолчанию готовая копия получает суффикс
`-reviewed`. Для публикации проверенной копии файловая система каталога
назначения должна поддерживать жёсткие ссылки, как NTFS.

Официальная инструкция по локальным пакетам доступна в разделе
[Package your plugin](https://developers.openai.com/plugins/build/plugins).
